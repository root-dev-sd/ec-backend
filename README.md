# E-Care

This is the dev repo for the E-Care system.

How to run the code:

* `git clone` the repo
* `curl -fsSL https://deno.land/install.sh | sh` to download the **Deno** run time.
* `cd` to the direstory, and then run `deno run dev` to spin up the server.
> Note that the server won't return any valid responses since there will be no valid database instance to connect with, unless you are running the instance on the mother server.
